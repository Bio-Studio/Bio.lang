# MPS 原生 Generator（Rust 代码生成）

v1 管线用 `tools/mps_gen_rust.py`（Python，直接消费 structure.mps 模型文件）
生成 Rust 骨架，已落地可用。这里是**在 MPS 内挂接原生 generator 的指引**，
产出物与 v1 保持一致（ast_generated.rs 同款类型）。

## 在 MPS 里创建（30 秒）

1. 用 JetBrains MPS 打开本仓库（`bio/.mps` 工作区）。
2. 右键 `languages/biolang` → **New → Generator**（模块名自动为
   `biolang.generator`，存放于 `languages/biolang/generator/`）。
3. 在 generator 模块里新建 **mapping configuration**（映射配置），
   对 43 个概念各写一条 **reduction rule**：概念 → Rust 代码模板。
4. 生成语言（Ctrl+F9）→ 对 sandbox 模型跑 **Apply Generator**，
   输出 Rust 源码到 `languages/biolang/generator/classes_gen/`（或自定输出路径）。

## 备选：手工创建模块描述符

MPS 里 New → Generator 是最稳的（描述符 UUID 自动生成）。若坚持手写，
参考结构：

```xml
<!-- languages/biolang/generator/biolang.generator.mpl -->
<language namespace="biolang.generator" uuid="<随机-uuid>" languageVersion="0" moduleVersion="0">
  <models>
    <modelRoot contentPath="${module}" type="default">
      <sourceRoot location="generatorModels" />
    </modelRoot>
  </models>
  <facets>
    <facet type="generator" compile="mps" classes="mps" ext="yes">
      <classes generated="true" path="${module}/classes_gen" />
    </facet>
  </facets>
  <dependencies>
    <dependency reexport="false">982ae924-c56d-43b8-bf9b-3f5c024d8417(biolang)</dependency>
  </dependencies>
</language>
```

并在 `.mps/modules.xml` 登记：
`<modulePath path="$PROJECT_DIR$/languages/biolang/generator/biolang.generator.mpl" folder="languages" />`

> 注意：MPS 若报描述符格式错误，直接删掉手写文件改用 New → Generator。

## 建议映射策略（与 v1 生成器对齐）

- 概念 → Rust `struct`/`enum`：抽象概念（Declaration/Statement/Expression/Type）
  生成 enum，具体概念生成 struct；
- 属性（dataType=string）→ `String` 字段；链接按基数 →
  `Vec<..>` / `Box<..>` / `Option<Box<..>>`；
- reduction rule 输出头注释 `// GENERATED by MPS — DO NOT EDIT BY HAND`，
  与 `tools/mps_gen_rust.py` 保持一致，方便 diff 对照。
